 🤖 AI-Powered Job Portal | Java, Spring Boot Microservices & React

A full-stack AI-powered recruitment platform designed to streamline the hiring process by connecting job seekers and employers through intelligent candidate screening, automated resume analysis, and modern recruitment workflows.

Built using **Java, Spring Boot Microservices, React, PostgreSQL, Apache Kafka, Spring Cloud, Docker, and Artificial Intelligence**.

🚀 Key Features

 👨‍💼 Employer Features

- Search, filter, and review candidate applications.
- View candidate profiles and uploaded resumes.
- Track candidate application and hiring status.
- AI-powered candidate evaluation and ranking.
- Automatically identify suitable candidates.
- Shortlist, review, or reject applications based on evaluation results.

👨‍🎓 Job Seeker Features

- User registration and secure authentication.
- Create and manage candidate profiles.

- Search and filter job opportunities.

🤖 AI-Powered Recruitment

- Analyze resumes using AI integration.
- Identify missing skills and information.
- Generate personalized resume improvement suggestions.
- Evaluate candidate suitability against job requirements.
- Generate AI-based candidate evaluation scores.
- Identify and shortlist relevant applicants.
- Support recruiters with intelligent screening recommendations.

🏗️ System Architecture

The application follows a microservices-based architecture in which individual services handle specific business responsibilities.

Core architectural components:

1. API Gateway: Provides a centralized entry point for client requests.
2. Eureka Server:Handles service registration and discovery.
3. Config Server:Centralizes microservice configuration.
4. Authentication Service: Manages user authentication and authorization.
5. Job Service: Handles job creation, management, and searching.
6. Application Service: Manages candidate applications and hiring workflows.
7. AI Service: Supports resume analysis and candidate evaluation.
8. afka: Enables asynchronous, event-driven communication between services.
9. PostgreSQL: Stores application and recruitment data.
